# DWDM — карта спектра

Однофайловая локальная страница для просмотра частотных измерений, подписывания каналов и отображения областей Казахстана.

## Запуск

Откройте `index.html` в браузере. В разделе загрузки выберите TXT-отчёт DWDM или CSV/TXT с частотой и мощностью.

В репозиторий загружается только сайт. Файлы измерений в нём не хранятся.
